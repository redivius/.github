# Redivius
---

## What is the initiative?

The idea is to use, other-wise, electronic waste; data-center's GPUs, to build useable 
machines for everyday people

## How?

There will be two main projects: redivius-os, a Unix-like OS with used GPUs as
the main target; And Coeus, a translation-layer from Windows x86_64 to AMDGPU.
