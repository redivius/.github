# Redivius
---
## What is the initiative?
The idea is to use, otherwise, electronic waste; 
data-center GPUs, to build usable machines for 
everyday people.

## How?
There will be two main projects:
- **Redivius OS**, a Unix-like OS with used GPUs 
  as the main target;
- **Coeus**, a compatibility layer from Win32 API 
  to Redivius OS, enabling Windows applications to 
  run natively on GPU hardware.
